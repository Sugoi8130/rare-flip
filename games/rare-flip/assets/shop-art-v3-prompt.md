Use case: stylized-concept. Asset type: ONE square production sprite atlas PNG, actual transparent alpha background, exactly 3x3 equally sized cells. Reference image is STYLE AND ENVIRONMENT REFERENCE ONLY. Create a NEW collectible cosmetic item set for this 2D pixel arcade, deliberately distinct from the room's existing purple/gold furniture. Rich professional 16-bit RPG pixel art, crisp stepped pixels, detailed material shading, 3/4 front view matching props, dark indigo outer outline plus small ivory/cyan edge highlights for high readability on dark violet backgrounds. Limited vivid palettes of pearl ivory, turquoise mint, peach/coral, sky blue. Do NOT make gold chests, purple arcade cabinets, green ferns, gold crowns, wizard hats or leather backpacks. Exact cells, object occupies central 65% of each cell with at least 15% transparent padding each side; nothing overlaps neighboring cells. Row3 EFFECTS left-to-right: coral pink heart bubbles with ivory highlights in an orbit; aqua mint crescent orbit with white pixel stars; rainbow confetti burst mainly coral cyan ivory lime, clear separated pixel particles. Actual transparent alpha all around items. Each entire object and all particles fit fully inside its own equal square cell.
